# Habit Tracker (GUI Version)

Программа с графическим интерфейсом для добавления и отслеживания своих привычек.

## 🚀 Как запустить

Вам не нужно устанавливать Python или зависимости. 

1. Перейдите в раздел **Releases** справа.
2. Скачайте готовый файл `GUI_Habit.exe`.
3. Запустите его на компьютере.

*При первом запуске программа автоматически создаст файл `Habit.json` для сохранения вашей статистики.*
