# Habit Tracker

Программа для добавления и отслеживания своих привычек.

# Файл данных

При первом запуске программа автоматически создает файл Habit.json, если он отсутствует.

В этом файле хранятся все добавленные привычки и статистика их выполнения.

**Создавать Habit.json вручную не требуется.**

# Возможности программы:
- Добавление привычек
- Просмотр списка привычек
- Отметка выполнения привычки
- Удаление привычек
- Переименование привычек
- Просмотр статистики серий


## Запуск

Запуск через .exe файл, который лежит в папке dist


## Функции

ADD - добавить новую привычки
DONE - отметить сегодняшний день в привычке
SHOW STATS - вывод статистики привычки
REMOVE - удалить привычку
RENAME HABIT - переименовать привычку
LIST HABITS - список привычек
