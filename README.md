# Habit Tracker

Программа для добавления и отслеживания своих привычек.


# Возможности программы:
- Добавление привычек
- Просмотр списка привычек
- Отметка выполнения привычки
- Удаление привычек
- Переименование привычек
- Просмотр статистики серий


## Запуск

Запускайте через терминал или PowerShell

Сначала переходите в папку, где находится файл Habit.py:

cd "Путь к папке"

Для запуска команды используйте:

py Habit.py команда "Имя привычки"


## Команды

add "Имя привычки" - добавляет новую привычку
list - выводит список всех привычек, дополнительные аргументы не требуются.
done "Имя привычки" - отмечает выполнение привычки за сегодняшний день.
remove "Имя привычки" - удаляет выбранную привычку.
rename "Имя привычки" "Новое имя привычки"- переименовывает выбранную привычку.
stats "Имя привычки" - выводит статистику выбранной привычки.

ВАЖНО!!!!

Рекомендуется заключать названия привычек в кавычки. Это особенно важно, если название содержит пробелы.

Пример:

py Habit.py rename "Python for Beginner" "Py for Beginner"
